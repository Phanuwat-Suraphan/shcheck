# คู่มือสำหรับครูและบุคลากร

ระบบลงเวลาปฏิบัติงานออนไลน์ โรงเรียนวัดเสาหิน จังหวัดเชียงใหม่ — ใช้งานผ่านโทรศัพท์มือถือหรือคอมพิวเตอร์ ไม่ต้องติดตั้งแอป

## 1. ก่อนเริ่มใช้งาน

1. เปิดลิงก์ (URL) ของระบบที่ได้รับจากโรงเรียน ด้วย **Chrome (Android)** หรือ **Safari (iPhone/iPad)**
   - ถ้าได้รับลิงก์ทาง LINE ให้กดเมนู ⋯ แล้วเลือก **“เปิดในเบราว์เซอร์”** (เบราว์เซอร์ในแอปแชทมักบล็อก GPS)
2. แนะนำให้ **เพิ่มไปยังหน้าจอหลัก** (Chrome: ⋮ → เพิ่มลงในหน้าจอหลัก / Safari: ปุ่มแชร์ → เพิ่มไปยังหน้าจอโฮม) จะเปิดได้เหมือนแอป
3. เปิด **ตำแหน่ง (Location/GPS)** ของโทรศัพท์

## 2. สมัครสมาชิก

1. หน้าเข้าสู่ระบบ → กด **สมัครสมาชิก**
2. กรอกข้อมูลให้ตรงความจริง:
   - **ชื่อ-นามสกุล** (รวมคำนำหน้า และเว้นวรรคระหว่างชื่อกับนามสกุล) เช่น `นางสาวสมศรี ใจดี`
   - **รหัสประจำตัวบุคลากร** — ห้ามซ้ำกับผู้อื่น
   - **ตำแหน่ง** — ผู้อำนวยการ / ครู / บุคลากรทางการศึกษา / เจ้าหน้าที่อื่น ๆ
   - **ชื่อผู้ใช้ (Username)** — ภาษาอังกฤษตัวเล็ก ขึ้นต้นด้วยตัวอักษร 4–30 ตัว เช่น `somsri.j`
   - **รหัสผ่าน** — อย่างน้อย 8 ตัว มีทั้งตัวอักษรภาษาอังกฤษและตัวเลข ไม่มีชื่อผู้ใช้อยู่ในรหัสผ่าน และไม่ใช่รหัสที่เดาง่าย (เช่น `12345678`, `password1`) ระบบแสดงเครื่องหมาย ✓ เมื่อผ่านแต่ละเกณฑ์
3. อ่านและติ๊กยอมรับ **นโยบายการใช้ข้อมูลตำแหน่ง (GPS)** → กด **ส่งข้อมูลสมัครสมาชิก**
4. ระบบแสดง **สมัครสมาชิกสำเร็จ** พร้อม **เลขอ้างอิง** — บัญชีอยู่ในสถานะ **รออนุมัติ** ยังเข้าสู่ระบบไม่ได้จนกว่าผู้ดูแลระบบจะอนุมัติ

## 3. เข้าสู่ระบบ / ออกจากระบบ

- กรอกชื่อผู้ใช้และรหัสผ่าน → **เข้าสู่ระบบ** (กดไอคอน 👁 เพื่อแสดง/ซ่อนรหัสผ่าน, ติ๊ก “จดจำชื่อผู้ใช้” เพื่อไม่ต้องพิมพ์ครั้งหน้า)
- ใส่รหัสผ่านผิด 5 ครั้ง บัญชีจะถูกล็อกชั่วคราว 15 นาที (ผู้ดูแลระบบปลดล็อกได้)
- ระบบออกจากระบบอัตโนมัติเมื่อไม่ได้ใช้งาน 30 นาที (ค่าเริ่มต้น) — เข้าสู่ระบบใหม่ได้ทันที
- **ลืมรหัสผ่าน**: กด **ลืมรหัสผ่าน?** ในหน้าเข้าสู่ระบบ → กรอกชื่อผู้ใช้ หรือรหัสประจำตัวบุคลากร (+ ช่องทางติดต่อกลับ ถ้าต้องการ) → **ส่งคำขอ**
  1. ผู้ดูแลระบบจะเห็นคำขอในระบบ และยืนยันตัวตนท่าน (พบตัว/โทรศัพท์)
  2. ผู้ดูแลระบบแจ้ง **รหัสผ่านชั่วคราว** ให้ท่านโดยตรง
  3. เข้าสู่ระบบด้วยรหัสผ่านชั่วคราว → ระบบให้ตั้งรหัสผ่านใหม่ทันที
  - การส่งคำขอไม่ได้เปลี่ยนรหัสผ่านเดิม หากนึกรหัสเดิมได้ก็ยังใช้ได้ตามปกติ
- ออกจากระบบ: ไอคอน ⎋ มุมขวาบน หรือเมนู **บัญชี → ออกจากระบบ** (ควรทำทุกครั้งเมื่อใช้เครื่องคนอื่น)

## 4. ลงเวลาเข้างาน / ออกงาน (หน้า “ลงเวลา”)

หน้าหลักแสดง ชื่อ-ตำแหน่ง, วันที่ พ.ศ. และนาฬิกา (เวลาจากเซิร์ฟเวอร์ ไม่ใช่เวลาในโทรศัพท์), ปุ่มลงเวลา, สถานะวันนี้ และสถานะ GPS

### ลงเวลาเข้างาน
1. เมื่อมาถึงโรงเรียน กดปุ่มสีเขียว **ลงเวลาเข้างาน**
2. ครั้งแรกเบราว์เซอร์จะถามสิทธิ์ตำแหน่ง → กด **อนุญาต (Allow)**
3. ระบบแสดงขั้นตอน: อ่านพิกัด → ตรวจความแม่นยำ → ตรวจระยะห่างจากโรงเรียน → บันทึกเวลา (รอไม่เกินประมาณ 15 วินาที)
4. สำเร็จ: ขึ้น ✅ **ลงเวลาเข้างานสำเร็จ** พร้อมเวลา สถานะ (ตรงเวลา/มาสาย กี่นาที) ระยะห่างจากโรงเรียน (สีเขียว) และปุ่มดูตำแหน่งบนแผนที่

### ลงเวลาออกงาน
- กดปุ่มสีน้ำเงิน **ลงเวลาออกงาน** → กด **ลงเวลาออก** ในกล่องยืนยัน (ต้องลงเวลาเข้าก่อน)
- ค่าเริ่มต้น **ไม่ต้องตรวจ GPS** — ลงเวลาออกได้แม้ออกจากโรงเรียนไปแล้ว (ระบบบันทึกเวลาของเซิร์ฟเวอร์ ณ ตอนกด) หากโรงเรียนเปิดการตรวจ GPS ขาออก ต้องอยู่ในพื้นที่โรงเรียนเหมือนตอนลงเวลาเข้า
- หากกดก่อนเวลาเลิกงาน ระบบจะเตือนและบันทึกสถานะ “ออกก่อนเวลา”

### กติกาสำคัญ
- 1 วัน ลงเวลาเข้าได้ 1 ครั้ง และออกได้ 1 ครั้ง (กดแล้วปุ่มจะถูกปิด)
- **ลงเวลาเข้า** ต้องอยู่ **ในรัศมีที่โรงเรียนกำหนด** (เริ่มต้น 150 ม.) และสัญญาณ GPS แม่นยำพอ (คลาดเคลื่อนไม่เกิน 50 ม.)
- เวลาที่บันทึกคือ **เวลาของเซิร์ฟเวอร์** การปรับนาฬิกาโทรศัพท์ไม่มีผล
- ระบบใช้ GPS **เฉพาะตอนกดปุ่ม** ไม่ติดตามตำแหน่งตลอดวัน
- การใช้แอปปลอมตำแหน่ง (Fake GPS) ถือเป็นการให้ข้อมูลเท็จต่อทางราชการ

### เมื่อลงเวลาไม่สำเร็จ

| ข้อความ | วิธีแก้ |
|---|---|
| ❌ อยู่นอกพื้นที่โรงเรียน (ห่าง xxx ม.) | เดินเข้ามาในบริเวณโรงเรียนแล้วลองใหม่ / กด “ตรวจสอบตำแหน่งของฉัน” เพื่อดูระยะ |
| ❌ สัญญาณ GPS ไม่แม่นยำพอ | ออกไปที่โล่ง ห่างหลังคาโลหะ เปิด Wi-Fi รอ 10–20 วินาทีแล้วลองใหม่ |
| ❌ ไม่ได้รับอนุญาตให้เข้าถึงตำแหน่ง | ดูหัวข้อ 5 หรือกด **วิธีเปิด GPS** ในหน้าลงเวลา |
| ❌ ลงเวลาเข้างานของวันนี้แล้ว | ลงเวลาไปแล้ว ไม่ต้องกดซ้ำ |
| ❌ กรุณาลงเวลาเข้างานก่อน | ลืมลงเวลาเข้า → ยื่น **คำร้องแก้ไขเวลา** |
| ❌ ขณะนี้มีผู้ใช้งานพร้อมกันจำนวนมาก | รอ 2–3 วินาทีแล้วกดใหม่ |

## 5. วิธีเปิด/อนุญาต GPS

**Android (Chrome)**
1. ปัดหน้าจอลงจากด้านบน → เปิด **ตำแหน่ง**
2. ใน Chrome แตะไอคอนหน้าแถบที่อยู่ → **สิทธิ์** → **ตำแหน่ง** → **อนุญาต**
3. การตั้งค่า → ตำแหน่ง → เปิด **ความแม่นยำของตำแหน่งใน Google**

**iPhone/iPad (Safari)**
1. การตั้งค่า → ความเป็นส่วนตัวและความปลอดภัย → **บริการหาตำแหน่ง** → เปิด
2. ในรายการเดียวกัน → **เว็บไซต์ Safari** → **ขณะใช้แอป** และเปิด **ตำแหน่งที่แน่นอน**
3. ใน Safari แตะ **aA** → การตั้งค่าเว็บไซต์ → ตำแหน่ง → **อนุญาต**

## 6. ดูประวัติและสถิติของตนเอง

- หน้า **ลงเวลา** แสดงสรุปเดือนนี้: มาปฏิบัติงาน (วัน), มาสาย (ครั้ง/นาที), ลา (วัน), ลงเวลาไม่ครบ (ครั้ง), ขาดงาน (วัน) และประวัติ 7 รายการล่าสุด
- เมนู **ประวัติ** → เลือกเดือน/ปี (พ.ศ.) เพื่อดูย้อนหลังรายวัน: เวลาเข้า-ออก สถานะ จำนวนนาทีที่สาย หมายเหตุ

## 7. แจ้งการลา (เมนู “การลา”) — แตะครั้งเดียวแล้วยืนยัน

1. **เลือกวันที่ลา**: **วันนี้** (ค่าเริ่มต้น) / **พรุ่งนี้** / **เลือกวันที่เอง** (บันทึก **ย้อนหลัง** หรือ **ล่วงหน้า** ได้ และเลือกเป็นช่วงหลายวันได้)
2. (ถ้าต้องการ) เลือก **ครึ่งวันเช้า/ครึ่งวันบ่าย** — ใช้ได้เมื่อลาวันเดียว
3. **แตะประเภทการลา**: ลาป่วย · ลากิจ · ลาพักผ่อน · ลาคลอดบุตร · ไปราชการ · **อื่น ๆ (พิมพ์เอง)**
4. กล่อง **ยืนยันการลา** จะแสดงประเภทและวันที่ให้ตรวจ → (ไม่บังคับ) พิมพ์เหตุผล/แนบเอกสาร → กด **ยืนยันการลา**
   - ถ้าเลือก “อื่น ๆ” ต้องพิมพ์ชื่อการลาเอง เช่น *ลาอุปสมบท*, *ลาไปช่วยเหลือภริยาที่คลอดบุตร* (มีคำแนะนำให้เลือก)
5. ติดตามสถานะในรายการด้านล่าง: 🟡 รออนุมัติ / 🟢 อนุมัติแล้ว / 🔴 ไม่อนุมัติ

- โรงเรียนเลือกได้ว่าการลาที่ครูบันทึกเอง **ต้องรออนุมัติ** (ค่าเริ่มต้น) หรือ **มีผลทันที** — ข้อความใต้ปุ่มจะบอกว่าโรงเรียนตั้งไว้แบบใด
- ผู้บริหาร/ผู้ดูแลระบบสามารถ **บันทึกการลาให้แทน** ได้ (เช่น ครูโทรมาแจ้งลาป่วย) จะแสดงว่า “บันทึกโดย …” ในรายการของท่าน
- ระบบนับเฉพาะวันทำการ (ไม่นับเสาร์-อาทิตย์และวันหยุด) และไม่ให้บันทึกลาซ้อนช่วงที่มีใบลาอยู่แล้ว
- ยกเลิกเองได้เมื่อยังรออนุมัติ (หรือเมื่อโรงเรียนตั้งให้มีผลทันที) — ใบลาที่ผู้บริหารอนุมัติแล้วต้องให้ผู้บริหารยกเลิก
- วันที่ลาจะแสดงเป็น “ลา” ในสถิติ ไม่ใช่ “ขาดงาน”; ลาครึ่งวันเช้าแล้วมาทำงานช่วงบ่ายจะไม่ถูกนับว่ามาสาย

## 8. ยื่นคำร้องแก้ไขเวลา (เมนู “แก้ไขเวลา”)

ใช้เมื่อลืมลงเวลา โทรศัพท์แบตหมด GPS ขัดข้อง หรือกดผิด
1. เลือก **วันที่** (ย้อนหลังได้ไม่เกิน 30 วัน — ตามที่โรงเรียนกำหนด), **ประเภท** (เวลาเข้า/เวลาออก), **เวลาที่ถูกต้อง**
2. ระบุ **เหตุผล** และแนบ **หลักฐาน** (ถ้ามี) → **ส่งคำร้อง**
3. เมื่อผู้บริหาร/ผู้ดูแลอนุมัติ ระบบจะบันทึกเวลาใหม่ โดย **เก็บรายการเดิมไว้เป็นประวัติ** ทุกครั้ง (ตรวจสอบย้อนหลังได้)

## 9. บัญชีของฉัน

- ดูข้อมูลส่วนตัว (หากไม่ถูกต้องให้แจ้งผู้ดูแลระบบแก้ไข)
- **เปลี่ยนรหัสผ่าน**: กรอกรหัสผ่านปัจจุบัน + รหัสผ่านใหม่ 2 ครั้ง → เมื่อเปลี่ยนแล้ว อุปกรณ์อื่นที่เคยเข้าสู่ระบบไว้จะถูกออกจากระบบทั้งหมด

## 10. คำถามที่พบบ่อย

- **เปลี่ยนโทรศัพท์ได้ไหม?** ได้ เข้าสู่ระบบด้วยชื่อผู้ใช้เดิมบนเครื่องใหม่
- **ไม่มีอินเทอร์เน็ตลงเวลาได้ไหม?** ไม่ได้ ต้องเชื่อมต่ออินเทอร์เน็ต (มือถือหรือ Wi-Fi ของโรงเรียน)
- **วันเสาร์มาทำงานลงเวลาได้ไหม?** ได้ ถ้าโรงเรียนเปิดให้ลงเวลาวันหยุด จะบันทึกเป็น “ปฏิบัติงานวันหยุด”
- **ใครเห็นตำแหน่งของฉันบ้าง?** เฉพาะผู้บริหารและผู้ดูแลระบบ เห็นเฉพาะตำแหน่ง ณ ตอนกดลงเวลา และพิกัดจะถูกลบอัตโนมัติเมื่อครบระยะเวลาเก็บรักษา (เริ่มต้น 365 วัน)
