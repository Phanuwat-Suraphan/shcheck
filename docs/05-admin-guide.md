# คู่มือสำหรับผู้ดูแลระบบและผู้บริหาร

> ผู้ดูแลระบบ (ADMIN) ใช้ได้ทุกเมนู · ผู้บริหาร (EXECUTIVE) ใช้ได้เฉพาะ ภาพรวม, อนุมัติการลา, คำร้องแก้ไขเวลา, รายงานและสถิติ, ปฏิทิน (ดูอย่างเดียว)
>
> เข้าหน้านี้โดยเข้าสู่ระบบตามปกติ แล้วกดปุ่ม **ผู้บริหาร/Admin** มุมขวาบน (ผู้บริหาร/Admin ใช้หน้า “ลงเวลา” ลงเวลาของตนเองได้เหมือนครูทุกประการ)

## 1. ภาพรวม (Dashboard)

| การ์ด | ความหมาย |
|---|---|
| บุคลากรทั้งหมด | บัญชีที่สถานะ “ใช้งาน” |
| มาปฏิบัติงานวันนี้ | ลงเวลาเข้าแล้ว (รวมมาสาย) |
| มาสาย | ลงเวลาเข้าหลังเวลาที่ถือว่าสาย |
| ลา | มีใบลาที่อนุมัติครอบคลุมวันนี้ |
| ขาดงาน | วันทำงาน ไม่ลงเวลา ไม่มีใบลา **และพ้นเวลาเลิกงานแล้ว** (ก่อนเวลาเลิกงานนับเป็น “ยังไม่ได้ลงเวลา”) |
| ยังไม่ได้ลงเวลา | ยังไม่ลงเวลาเข้า และยังไม่ถึงเวลาเลิกงาน |
| ลงเวลาไม่ครบ | ลงเวลาเข้าแต่ไม่ลงเวลาออก (หลังเวลาเลิกงาน) หรือมีเวลาออกแต่ไม่มีเวลาเข้า |
| สมัครสมาชิกรออนุมัติ | คลิกเพื่อไปหน้าอนุมัติ |

ด้านล่างมีแถบสัดส่วนสถานะวันนี้, กราฟการมาปฏิบัติงาน 7 วันทำงานล่าสุด และตารางรายบุคคล (ค้นหาได้) กด **รีเฟรช** เพื่อดูข้อมูลล่าสุด ตัวเลขสีแดงบนเมนูคือจำนวนรายการที่รอดำเนินการ

## 2. อนุมัติสมาชิก (ADMIN)

1. เมนู **อนุมัติสมาชิก** แสดงผู้สมัครทั้งหมด (ชื่อ, รหัส, ตำแหน่ง, ชื่อผู้ใช้, วันเวลาสมัคร)
2. ตรวจสอบตัวตน/รหัสบุคลากรกับทะเบียนจริง
3. **อนุมัติ** → เลือกประเภทผู้ใช้งาน (บุคลากร / ผู้บริหาร / ผู้ดูแลระบบ — ตำแหน่งผู้อำนวยการระบบจะเสนอ “ผู้บริหาร” ให้) → ผู้ใช้เริ่มลงเวลาและถูกนับสถิติตั้งแต่วันที่อนุมัติ
4. **ไม่อนุมัติ** → ระบุเหตุผล (ผู้สมัครจะเห็นข้อความเมื่อพยายามเข้าสู่ระบบ) — หากสมัครผิดและต้องการให้สมัครใหม่ด้วยรหัสเดิม ให้ **ลบบัญชี** ที่ไม่อนุมัติในเมนูจัดการสมาชิก

## 3. จัดการสมาชิก (ADMIN)

- ค้นหาจากชื่อ/รหัสบุคลากร/ชื่อผู้ใช้ และกรองตามสถานะ/ประเภท
- **เพิ่มบุคลากร**: กรอกข้อมูล + เลือกประเภท → ระบบสุ่ม **รหัสผ่านชั่วคราว 12 ตัว** แสดงเพียงครั้งเดียว → แจ้งเจ้าของบัญชีโดยตรง (ไม่ส่งในกลุ่มแชท) → ผู้ใช้ต้องตั้งรหัสใหม่เมื่อเข้าสู่ระบบ
- กด **จัดการ** ที่แถวบุคลากร:

| เมนู | ผลลัพธ์ |
|---|---|
| ดูประวัติการลงเวลา | เปิดรายงานรายบุคคลของคนนั้น |
| แก้ไขข้อมูล | ชื่อ, รหัส, ตำแหน่ง, ชื่อผู้ใช้, หมายเหตุ (ตรวจข้อมูลซ้ำให้อัตโนมัติ) |
| เปลี่ยนประเภทผู้ใช้ | บุคลากร ↔ ผู้บริหาร ↔ ผู้ดูแลระบบ (มีผลทันที) |
| รีเซ็ตรหัสผ่าน | สุ่มรหัสชั่วคราวใหม่ + บังคับเปลี่ยน + ออกจากระบบทุกอุปกรณ์ + ปลดล็อก |
| ปลดล็อกบัญชี | กรณีใส่รหัสผิดเกินกำหนด |
| ปิดใช้งาน / เปิดใช้งาน | ปิด = ออกจากระบบทันที เข้าสู่ระบบไม่ได้ และไม่นับสถิติหลังวันนี้ (ประวัติเดิมอยู่ครบ) — ใช้กับผู้ย้าย/ลาออก |
| ลบบัญชี | ลบได้เฉพาะบัญชีที่ **ไม่มีประวัติ** การลงเวลา/ลา/คำร้อง (มีประวัติให้ใช้ “ปิดใช้งาน” เพื่อความโปร่งใส) |

ข้อจำกัดเพื่อความปลอดภัย: เปลี่ยนสิทธิ์/สถานะ/ลบบัญชีของตนเองไม่ได้ และระบบต้องมีผู้ดูแลระบบที่ใช้งานอยู่อย่างน้อย 1 คนเสมอ (แนะนำให้มี Admin 2 คน)

## 4. การลา: อนุมัติ และบันทึกการลาให้บุคลากร (ADMIN + ผู้บริหาร)

**บันทึกการลาให้บุคลากร** (เช่น ครูโทรมาแจ้งลา) — ปุ่ม **บันทึกการลาให้บุคลากร** ในเมนูนี้ หรือเมนู **จัดการ → บันทึกการลา** ที่รายชื่อบุคลากร
1. เลือกบุคลากร → เลือกวันที่ (วันนี้/พรุ่งนี้/เลือกเอง — ย้อนหลังหรือล่วงหน้าได้) → ครึ่งวัน (ถ้ามี)
2. แตะประเภทการลา (ลาป่วย/ลากิจ/ลาพักผ่อน/ลาคลอดบุตร/ไปราชการ/อื่น ๆ พิมพ์เอง) → กล่องยืนยัน → **บันทึกการลา**
3. ใบลาที่บันทึกให้ผู้อื่น **อนุมัติทันที** (บันทึกชื่อผู้บันทึก + Audit Log) — ถ้าบันทึกให้ตนเองจะรอผู้บริหาร/ผู้ดูแลท่านอื่นอนุมัติ

**อนุมัติใบลาที่ครูบันทึกเอง**
- กรอง: รออนุมัติ / อนุมัติแล้ว / ไม่อนุมัติ / ทั้งหมด และค้นหาชื่อ
- แต่ละใบลาแสดง ประเภท, จำนวนวันทำการ, ช่วงวันที่, เหตุผล, เอกสารแนบ (กด **เอกสารแนบ** เพื่อดู/ดาวน์โหลด), ผู้บันทึก
- **อนุมัติ** (ใส่ความเห็นได้) / **ไม่อนุมัติ** (ต้องระบุเหตุผล) / **ยกเลิกการอนุมัติ** (กรณีอนุมัติผิด — ต้องระบุเหตุผล)
- **ไม่สามารถพิจารณาใบลาของตนเองได้** ต้องให้ผู้บริหาร/ผู้ดูแลท่านอื่นพิจารณา
- ไม่ต้องการขั้นตอนอนุมัติ? ปิดสวิตช์ **การลาที่บุคลากรบันทึกเองต้องรออนุมัติ** ในหน้าตั้งค่าระบบ → ครูแตะ + ยืนยันแล้วมีผลทันที (ยังตรวจสอบย้อนหลังได้ทุกรายการ)
- ทุกการบันทึก/พิจารณาถูกบันทึกใน Audit Log

## 5. คำร้องแก้ไขเวลา (ADMIN + ผู้บริหาร)

- แต่ละคำร้องแสดง วันที่, เวลาที่ขอแก้, เหตุผล, หลักฐาน และ **เวลาปัจจุบันในระบบ** (เข้า/ออก) เพื่อเปรียบเทียบ
- **อนุมัติและปรับเวลา**: ระบบเพิ่มรายการเวลาใหม่ (ที่มา = คำร้อง) และทำเครื่องหมายรายการเดิมว่า “ถูกแทนที่” — ไม่มีการลบ, คำนวณสาย/ออกก่อนเวลาใหม่ตามการตั้งค่า, บันทึก Audit Log พร้อมข้อมูลก่อน/หลัง
- ระบบไม่ยอมให้อนุมัติถ้าเวลาไม่สมเหตุสมผล (เช่น เวลาออกก่อนเวลาเข้า)
- **ไม่อนุมัติ** ต้องระบุเหตุผล; พิจารณาคำร้องของตนเองไม่ได้

## 6. รายงานและสถิติ (ADMIN + ผู้บริหาร)

| รายงาน | เลือก | เนื้อหา |
|---|---|---|
| รายวัน | วันที่ | ทุกคน: เวลาเข้า/ออก, สถานะ, สาย (นาที), ระยะห่าง, หมายเหตุ + ลิงก์ตำแหน่งตอนเข้า/ออก · สรุป: มา/สาย/ลา/ขาด/ไม่ลงเวลาเข้า/ไม่ลงเวลาออก/ยังไม่ลงเวลา · แถบสัดส่วน |
| รายเดือน | เดือน + ปี | รายบุคคล: วันทำงาน, วันมา, สาย (ครั้ง), ลา (วัน), ขาด (วัน), ไม่ครบ (ครั้ง), เวลาเข้าเฉลี่ย, เวลาออกเฉลี่ย, ร้อยละการมา · กราฟรายวัน |
| รายปี | ปี (ม.ค.–ธ.ค.) | เปรียบเทียบ 12 เดือน + สถิติรายบุคคลทั้งปี · กราฟแนวโน้มร้อยละ + กราฟแท่งรายเดือน |
| รายบุคคล | บุคลากร + ช่วงวันที่ (≤ 1 ปี) | ประวัติรายวันทั้งหมด + รายการลา + สรุป |

- ทุกรายงานมี **หัวกระดาษทางการ**: ชื่อโรงเรียนวัดเสาหิน จังหวัดเชียงใหม่, ชื่อรายงาน, ช่วงวันที่, วันที่จัดทำรายงาน/ผู้จัดทำ, ตาราง, สรุปผล และช่องลงนามผู้จัดทำ/ผู้อำนวยการ
- **Export Excel (.xlsx)** และ **Export PDF** (A4 แนวนอน) — ไฟล์ดาวน์โหลดลงเครื่องทันที (ชื่อไฟล์เช่น `WatSaoHin_Attendance_Monthly_2026-11.xlsx`)
- **พิมพ์รายงาน** — เปิดหน้าต่างพิมพ์ของเบราว์เซอร์ (เลือก “บันทึกเป็น PDF” ได้)
- ตัวเลขวันนี้: “ขาดงาน” จะนับหลังเวลาเลิกงานเท่านั้น; ระบบไม่นับวันในอนาคต

## 7. ปฏิทินวันหยุด (ADMIN แก้ไข / ผู้บริหารดู)

- **วันทำงานประจำสัปดาห์** ตั้งในหน้าตั้งค่า (เริ่มต้น จันทร์–ศุกร์)
- **เพิ่มวันหยุด/วันทำงานพิเศษ**: เลือกช่วงวันที่ + ประเภท + ชื่อ เช่น
  - วันหยุดราชการ: วันมาฆบูชา, วันหยุดชดเชย
  - วันหยุดพิเศษ: ปิดภาคเรียน, หยุดกีฬาสี
  - วันทำงานพิเศษ: ทำงานวันเสาร์ชดเชย (ระบบจะนับเป็นวันทำงาน)
- ปุ่ม **เพิ่มวันหยุดราชการที่มีวันที่คงที่ของปีนี้** เพิ่ม 14 วัน (ขึ้นปีใหม่, จักรี, สงกรานต์ 3 วัน, ฉัตรมงคล, 3 มิ.ย., 28 ก.ค., 12 ส.ค., 13 ต.ค., 23 ต.ค., 5 ธ.ค., 10 ธ.ค., 31 ธ.ค.) — **วันหยุดทางพุทธศาสนา วันหยุดชดเชย และวันหยุดพิเศษตามมติ ครม. ต้องเพิ่มเองตามประกาศแต่ละปี**
- ควรตั้งปฏิทินล่วงหน้า เพราะวันหยุดมีผลต่อการนับ “ขาดงาน” และจำนวนวันลา

## 8. ตั้งค่าระบบ (ADMIN)

| กลุ่ม | การตั้งค่า | ค่าเริ่มต้น |
|---|---|---|
| พื้นที่ลงเวลา | ละติจูด/ลองจิจูดโรงเรียน (ปุ่ม “ใช้ตำแหน่งปัจจุบันของฉัน” / “ดูบนแผนที่”) | ว่าง (ต้องตั้ง) |
| | รัศมีที่อนุญาต (ม.) | 150 |
| | ค่าความคลาดเคลื่อน GPS สูงสุด (ม.) | 50 |
| | ลงเวลาออกงานต้องตรวจ GPS (ลงเวลาเข้าตรวจเสมอ) | ปิด — ลงเวลาออกได้ทุกที่ |
| เวลาปฏิบัติงาน | เวลาเริ่มงาน / ถือว่าสายเมื่อลงเวลาหลัง / เวลาเลิกงาน / เปิดให้ลงเวลาเข้าตั้งแต่ | 08:00 / 08:30 / 16:30 / 05:00 (ตัวอย่าง) |
| | วันทำงานประจำสัปดาห์, อนุญาตลงเวลาวันหยุด | จ–ศ, เปิด |
| ความปลอดภัย | ออกจากระบบอัตโนมัติ (นาที), ใส่รหัสผิดได้ (ครั้ง), ระยะเวลาล็อก (นาที), เปิดรับสมัครสมาชิก | 30, 5, 15, เปิด |
| ข้อมูล | ระยะเวลาเก็บพิกัด GPS (วัน), ยื่นคำร้องย้อนหลังได้ (วัน) | 365, 30 |
| การลา | การลาที่บุคลากรบันทึกเองต้องรออนุมัติ | เปิด |

- “ถือว่าสายเมื่อลงเวลาหลัง 08:30” หมายถึง ลงเวลา 08:30:59 ยังไม่สาย, ตั้งแต่ 08:31:00 สาย และนับนาทีที่สายจากเวลาเริ่มงาน (เช่น เริ่ม 08:00 มา 08:45 = สาย 45 นาที)
- การเปลี่ยนเวลาทำงานมีผลกับการลงเวลา **ตั้งแต่ขณะนั้น** ข้อมูลเก่าคงสถานะตามกติกาเดิม หากต้องการคำนวณเดือนใดใหม่ด้วยกติกาใหม่ ใช้ **งานบำรุงรักษา → คำนวณสรุปรายวันใหม่**
- ทุกการแก้ไขบันทึกใน Audit Log (ค่าเดิม → ค่าใหม่)
- เปิดสวิตช์ **ยืนยันว่าได้ตรวจสอบการตั้งค่าตามระเบียบของโรงเรียนแล้ว** เมื่อพร้อมใช้งานจริง

**งานบำรุงรักษาข้อมูล**
- **คำนวณสรุปรายวันใหม่** (เลือกเดือน): สร้างตาราง DailySummary ของเดือนนั้นใหม่จากรายการลงเวลาต้นฉบับ ใช้เมื่อมีการแก้ชีตโดยตรงหรือเปลี่ยนเวลาทำงาน/ปฏิทินย้อนหลัง
- **ลบพิกัด GPS ที่เกินระยะเวลาเก็บรักษาทันที**: ปกติระบบทำอัตโนมัติทุกคืน 02:00 น.
- **พื้นที่ Google Drive**: แสดงพื้นที่ที่ใช้ของบัญชีระบบ และหน้าภาพรวมจะเตือนเมื่อใช้เกิน 85% (ถ้าเต็ม ระบบจะบันทึกข้อมูลไม่ได้ — ดู [ข้อจำกัด](08-limitations.md))

## 9. ประวัติการใช้งาน — Audit Log (ADMIN)

บันทึกการกระทำสำคัญทั้งหมดแบบเพิ่มต่อท้าย: เข้า/ออกจากระบบ, ล็อกบัญชี, สมัคร/อนุมัติ, แก้ไขข้อมูลบุคลากร, รีเซ็ตรหัสผ่าน, เปลี่ยนสิทธิ์, ลงเวลาไม่ผ่าน GPS (เก็บเฉพาะระยะทาง), การลา, คำร้อง (พร้อมข้อมูลก่อน/หลัง), ตั้งค่า, ปฏิทิน, ส่งออกรายงาน และ **ความพยายามเข้าถึงโดยไม่มีสิทธิ์** (แสดงป้ายสีแดง) — ค้นหาและกรองตามประเภทการกระทำได้

## 10. แนวปฏิบัติที่แนะนำ

- **ทุกวัน**: ดูภาพรวมหลังเวลาเลิกงาน, พิจารณาใบลา/คำร้องที่ค้าง
- **ทุกสัปดาห์**: ตรวจ Audit Log รายการสีแดง (ACCESS_DENIED / ล็อกบัญชี / ลงเวลาไม่ผ่าน GPS ซ้ำ ๆ)
- **ทุกเดือน**: ส่งออกรายงานรายเดือน (Excel/PDF) เสนอผู้อำนวยการ และสำรองไฟล์ฐานข้อมูล (ไฟล์ → ดาวน์โหลด .xlsx)
- **ต้นปี/ต้นภาคเรียน**: ตั้งปฏิทินวันหยุดทั้งปี, ตรวจรายชื่อบุคลากร ปิดใช้งานผู้ย้ายออก
- ห้ามแชร์ไฟล์ Google Sheets ฐานข้อมูลแบบสาธารณะ ห้ามลบ `PASSWORD_PEPPER` ใน Script Properties
- หลีกเลี่ยงการแก้ไขข้อมูลในชีตโดยตรง (จะไม่มี Audit Log) — ถ้าจำเป็นให้รัน “คำนวณสรุปรายวันใหม่” ของเดือนนั้นหลังแก้
