# คู่มือสำหรับผู้ดูแลระบบและผู้บริหาร

> ผู้ดูแลระบบ (ADMIN) ใช้ได้ทุกเมนู · ผู้บริหาร (EXECUTIVE) ใช้ได้เฉพาะ ภาพรวม, อนุมัติการลา, คำร้องแก้ไขเวลา, รายงานและสถิติ, ปฏิทิน (ดูอย่างเดียว)
>
> เข้าหน้านี้โดยเข้าสู่ระบบตามปกติ แล้วกดปุ่ม **ผู้บริหาร/Admin** มุมขวาบน (ผู้บริหาร/Admin ใช้หน้า “ลงเวลา” ลงเวลาของตนเองได้เหมือนครูทุกประการ)

## 1. ภาพรวม (Dashboard)

> **ผู้อำนวยการ/ผู้บริหารใช้โทรศัพท์:** เปิดแอปตามปกติ ถ้ามีงานรออนุมัติ หน้าแรกจะมีแถบสีส้ม **“งานรออนุมัติ”** แตะ **ไปอนุมัติ** ระบบเปิดหน้าใบลา/คำร้องที่รออยู่ให้ทันที ไม่ต้องหาเมนู

**การ์ดด้านบนของหน้าภาพรวม**
- **ประกาศถึงบุคลากร** (ADMIN + ผู้บริหาร) — กด **เขียนประกาศ** พิมพ์ข้อความ (ไม่เกิน 300 ตัวอักษร) และเลือกวันสุดท้ายที่แสดง (ไม่เกิน 90 วัน) → ครูทุกคนเห็นบนหน้าแรก · ประกาศใหม่แทนที่ประกาศเดิม · กด **ลบประกาศ** เพื่อเลิกแสดง
- **งานรอดำเนินการ** — ปุ่มลัดพร้อมจำนวน: ใบลารออนุมัติ, คำร้องแก้ไขเวลา, สมาชิกใหม่รออนุมัติ, ขอรีเซ็ตรหัสผ่าน (ไม่นับคำขอของตนเองซึ่งพิจารณาเองไม่ได้)
- **ตั้งค่าเริ่มต้นให้ครบ (x/6)** (ADMIN) — ระบบตรวจให้เองจากข้อมูลจริง แต่ละข้อมีปุ่ม **ไปทำ**: ตั้งพิกัดโรงเรียน · ตรวจเวลาทำงานแล้วกดยืนยัน · ใส่ชื่อผู้อำนวยการ · **เพิ่มวันปิดภาคเรียน/วันหยุดของโรงเรียน** (ถ้าไม่เพิ่ม ช่วงปิดภาคเรียนครูทุกคนจะถูกนับว่าขาดงาน) · เพิ่มครูและบุคลากร · ครูเริ่มลงเวลา — ครบแล้วการ์ดหายเอง (กด “ซ่อน” ได้)

| การ์ด | ความหมาย |
|---|---|
| บุคลากรทั้งหมด | บัญชีที่สถานะ “ใช้งาน” |
| มาปฏิบัติงานวันนี้ | ลงเวลาเข้าแล้ว (รวมมาสาย) |
| มาสาย | ลงเวลาเข้าหลังเวลาที่ถือว่าสาย |
| ลา | มีใบลาที่อนุมัติครอบคลุมวันนี้ |
| ขาดงาน | วันทำงาน ไม่ลงเวลา ไม่มีใบลา **และพ้นเวลาเลิกงานแล้ว** (ก่อนเวลาเลิกงานนับเป็น “ยังไม่ได้ลงเวลา”) |
| ยังไม่ได้ลงเวลา | ยังไม่ลงเวลาเข้า และยังไม่ถึงเวลาเลิกงาน |
| ลงเวลาไม่ครบ | ลงเวลาเข้าแต่ไม่ลงเวลาออก (หลังเวลาเลิกงาน) หรือมีเวลาออกแต่ไม่มีเวลาเข้า |
| สมัครสมาชิกรออนุมัติ | คลิกเพื่อไปหน้าอนุมัติ |

ด้านล่างมีแถบสัดส่วนสถานะวันนี้, กราฟการมาปฏิบัติงาน 7 วันทำงานล่าสุด และตารางรายบุคคล (ค้นหาได้) กด **รีเฟรช** เพื่อดูข้อมูลล่าสุด ตัวเลขสีแดงบนเมนูคือจำนวนรายการที่รอดำเนินการ

## 2. อนุมัติสมาชิก (ADMIN)

1. เมนู **อนุมัติสมาชิก** แสดงผู้สมัครทั้งหมด (ชื่อ, รหัส, ตำแหน่ง, ชื่อผู้ใช้, วันเวลาสมัคร)
2. ตรวจสอบตัวตน/รหัสบุคลากรกับทะเบียนจริง
3. **อนุมัติ** → เลือกประเภทผู้ใช้งาน (บุคลากร / ผู้บริหาร / ผู้ดูแลระบบ — ตำแหน่งผู้อำนวยการระบบจะเสนอ “ผู้บริหาร” ให้) → ผู้ใช้เริ่มลงเวลาและถูกนับสถิติตั้งแต่วันที่อนุมัติ
4. **ไม่อนุมัติ** → ระบุเหตุผล (ผู้สมัครจะเห็นข้อความเมื่อพยายามเข้าสู่ระบบ) — หากสมัครผิดและต้องการให้สมัครใหม่ด้วยรหัสเดิม ให้ **ลบบัญชี** ที่ไม่อนุมัติในเมนูจัดการสมาชิก

## 3. จัดการสมาชิก (ADMIN)

- ค้นหาจากชื่อ/รหัสบุคลากร/ชื่อผู้ใช้ และกรองตามสถานะ/ประเภท
- **เพิ่มบุคลากร**: กรอกข้อมูล (รหัสบุคลากรเว้นว่างได้ ระบบกำหนดให้) + เลือกประเภท → ระบบสุ่ม **รหัสผ่านชั่วคราว 12 ตัว** แสดงเพียงครั้งเดียว → แจ้งเจ้าของบัญชีโดยตรง (ไม่ส่งในกลุ่มแชท) → ผู้ใช้ต้องตั้งรหัสใหม่เมื่อเข้าสู่ระบบ
- กด **จัดการ** ที่แถวบุคลากร:

| เมนู | ผลลัพธ์ |
|---|---|
| ดูประวัติการลงเวลา | เปิดรายงานรายบุคคลของคนนั้น |
| บันทึกเวลาแทน (ลืมลงเวลา) | บันทึกเวลาเข้า/ออกให้ทันที (ดูหัวข้อ 5) |
| แก้ไขข้อมูล | ชื่อ, รหัส, ตำแหน่ง, ชื่อผู้ใช้, หมายเหตุ (ตรวจข้อมูลซ้ำให้อัตโนมัติ) |
| เปลี่ยนประเภทผู้ใช้ | บุคลากร ↔ ผู้บริหาร ↔ ผู้ดูแลระบบ (มีผลทันที) |
| รีเซ็ตรหัสผ่าน | สุ่มรหัสชั่วคราวใหม่ + บังคับเปลี่ยน + ออกจากระบบทุกอุปกรณ์ + ปลดล็อก |
| ปลดล็อกบัญชี | กรณีใส่รหัสผิดเกินกำหนด |
| ปิดใช้งาน / เปิดใช้งาน | ปิด = ออกจากระบบทันที เข้าสู่ระบบไม่ได้ และไม่นับสถิติหลังวันนี้ (ประวัติเดิมอยู่ครบ) — ใช้กับผู้ย้าย/ลาออก |
| ลบบัญชี | ลบได้เฉพาะบัญชีที่ **ไม่มีประวัติ** การลงเวลา/ลา/คำร้อง (มีประวัติให้ใช้ “ปิดใช้งาน” เพื่อความโปร่งใส) |

**คำขอรีเซ็ตรหัสผ่าน (ครูลืมรหัสผ่าน)**
- เมื่อครูกด “ลืมรหัสผ่าน?” แล้วส่งคำขอ จะมีตัวเลขสีแดงที่เมนู **จัดการสมาชิก**, แถบแจ้งในหน้าภาพรวม และกล่อง **คำขอรีเซ็ตรหัสผ่าน** ด้านบนตารางสมาชิก (แสดงเวลาที่ขอ + ข้อความ/ช่องทางติดต่อ)
- **ยืนยันตัวตนผู้ขอก่อน** (พบตัว/โทรศัพท์) แล้วกด **รีเซ็ตรหัสผ่าน** → แจ้งรหัสผ่านชั่วคราวที่ระบบแสดง (ครั้งเดียว) แก่เจ้าของบัญชีโดยตรง → คำขอหายไปอัตโนมัติ
- ถ้าไม่ใช่เจ้าของบัญชีเป็นผู้ขอ กด **ยกเลิกคำขอ** (รหัสผ่านเดิมไม่ถูกเปลี่ยน)
- ผู้ดูแลระบบลืมรหัสผ่านเอง: ให้ผู้ดูแลระบบอีกคนรีเซ็ตให้ หรือเจ้าของบัญชี Google ใช้ฟังก์ชัน `EmergencyResetAdmin()` ใน Apps Script (ดูคู่มือติดตั้ง)

ข้อจำกัดเพื่อความปลอดภัย: เปลี่ยนสิทธิ์/สถานะ/ลบบัญชีของตนเองไม่ได้ และระบบต้องมีผู้ดูแลระบบที่ใช้งานอยู่อย่างน้อย 1 คนเสมอ (แนะนำให้มี Admin 2 คน)

## 4. การลา: อนุมัติ และบันทึกการลาให้บุคลากร (ADMIN + ผู้บริหาร)

**บันทึกให้หลายคน (ไปราชการ / อบรม / ลา)** — ปุ่ม **บันทึกให้หลายคน** ในเมนูนี้: เลือกประเภท (ค่าเริ่มต้น “ไปราชการ”) วันที่ ช่วงเวลา รายละเอียด แล้วติ๊กเลือกบุคลากร (ค้นหาชื่อ/เลือกทั้งหมดได้) → **บันทึก N คน** ระบบบันทึกทีละคนตามขั้นตอนปกติ คนที่มีใบลาช่วงเดียวกันอยู่แล้วหรือปิดบัญชีจะถูกข้ามพร้อมเหตุผล (ของท่านเองจะรอผู้อื่นอนุมัติ)

**บันทึกการลาให้บุคลากร** (เช่น ครูโทรมาแจ้งลา) — ปุ่ม **บันทึกการลาให้บุคลากร** ในเมนูนี้ หรือเมนู **จัดการ → บันทึกการลา** ที่รายชื่อบุคลากร
1. เลือกบุคลากร → เลือกวันที่ (วันนี้/พรุ่งนี้/เลือกเอง — ย้อนหลังหรือล่วงหน้าได้) → ครึ่งวัน (ถ้ามี)
2. แตะประเภทการลา (ลาป่วย/ลากิจ/ลาพักผ่อน/ลาคลอดบุตร/ไปราชการ/อื่น ๆ พิมพ์เอง) → กล่องยืนยัน → **บันทึกการลา**
3. ใบลาที่บันทึกให้ผู้อื่น **อนุมัติทันที** (บันทึกชื่อผู้บันทึก + Audit Log) — ถ้าบันทึกให้ตนเองจะรอผู้บริหาร/ผู้ดูแลท่านอื่นอนุมัติ

**อนุมัติใบลาที่ครูบันทึกเอง**
- กรอง: รออนุมัติ / อนุมัติแล้ว / ไม่อนุมัติ / ทั้งหมด และค้นหาชื่อ
- แต่ละใบลาแสดง ประเภท, จำนวนวันทำการ, ช่วงวันที่, เหตุผล, เอกสารแนบ (กด **เอกสารแนบ** เพื่อดู/ดาวน์โหลด), ผู้บันทึก
- **อนุมัติ** (ใส่ความเห็นได้) / **ไม่อนุมัติ** (ต้องระบุเหตุผล) / **ยกเลิกการอนุมัติ** (กรณีอนุมัติผิด — ต้องระบุเหตุผล)
- **อนุมัติทั้งหมด** — เมื่อมีใบลารออนุมัติตั้งแต่ 2 รายการ กดครั้งเดียวอนุมัติทุกใบ (ยกเว้นของตนเอง) ระบบบันทึก Audit ทีละรายการเหมือนกดเอง
- **ไม่สามารถพิจารณาใบลาของตนเองได้** ต้องให้ผู้บริหาร/ผู้ดูแลท่านอื่นพิจารณา
- ไม่ต้องการขั้นตอนอนุมัติ? ปิดสวิตช์ **การลาที่บุคลากรบันทึกเองต้องรออนุมัติ** ในหน้าตั้งค่าระบบ → ครูแตะ + ยืนยันแล้วมีผลทันที (ยังตรวจสอบย้อนหลังได้ทุกรายการ)
- ทุกการบันทึก/พิจารณาถูกบันทึกใน Audit Log
- **พิมพ์ใบลา** ให้บุคลากรได้จากปุ่มบนใบลาแต่ละรายการ (แบบใบลาป่วย ลาคลอดบุตร ลากิจส่วนตัว / แบบใบลาพักผ่อน พร้อมสถิติการลาในปีงบประมาณ) — ช่องผู้มีอำนาจอนุญาตใช้ชื่อ/ตำแหน่งผู้อำนวยการจากหน้าตั้งค่า

## 5. คำร้องแก้ไขเวลา (ADMIN + ผู้บริหาร)

**บันทึกเวลาแทน (ครูลืมลงเวลา แล้วโทร/มาแจ้ง)** — มีผลทันที ไม่ต้องรอคำร้อง
- ทางลัดที่สุด: หน้า **ภาพรวม** → ตารางวันนี้ แถวของครูที่ยังไม่ลงเวลา/ไม่ลงเวลาออก กด **บันทึกเวลาแทน** (เลือกคน วันที่ และประเภทไว้ให้แล้ว) → ใส่เวลา → **บันทึกเวลา**
- หรือปุ่ม **บันทึกเวลาแทน (ครูลืมลงเวลา)** ในเมนูนี้ / เมนู **จัดการ → บันทึกเวลาแทน** ที่รายชื่อบุคลากร
- ระบบเก็บเป็นคำร้องที่อนุมัติแล้ว (ผู้บันทึก = ผู้อนุมัติ) รายการเวลาเดิมไม่ถูกลบ และบันทึก Audit `CORRECTION_RECORD_BY_ADMIN` · บันทึกให้ตนเองไม่ได้ · ย้อนหลังได้ไม่เกิน 1 ปี · ถ้าครูยื่นคำร้องของวัน/ประเภทนั้นไว้แล้ว ให้กดอนุมัติคำร้องนั้นแทน
- ครูที่ลืมลงเวลาเข้าแล้วยื่นคำร้องเวลาเข้าของวันนี้ **ลงเวลาออกตอนเย็นได้ตามปกติ** แล้วค่อยอนุมัติคำร้องภายหลัง

**พิจารณาคำร้องที่ครูยื่นเอง**
- **อนุมัติทั้งหมด** ใช้ได้เช่นเดียวกับใบลา — คำร้องที่เวลาไม่สมเหตุสมผล (เช่น เวลาออกก่อนเวลาเข้า) จะถูกข้ามและแจ้งเหตุผล

- แต่ละคำร้องแสดง วันที่, เวลาที่ขอแก้, เหตุผล, หลักฐาน และ **เวลาปัจจุบันในระบบ** (เข้า/ออก) เพื่อเปรียบเทียบ
- **อนุมัติและปรับเวลา**: ระบบเพิ่มรายการเวลาใหม่ (ที่มา = คำร้อง) และทำเครื่องหมายรายการเดิมว่า “ถูกแทนที่” — ไม่มีการลบ, คำนวณสาย/ออกก่อนเวลาใหม่ตามการตั้งค่า, บันทึก Audit Log พร้อมข้อมูลก่อน/หลัง
- ระบบไม่ยอมให้อนุมัติถ้าเวลาไม่สมเหตุสมผล (เช่น เวลาออกก่อนเวลาเข้า)
- **ไม่อนุมัติ** ต้องระบุเหตุผล; พิจารณาคำร้องของตนเองไม่ได้

## 6. รายงานและสถิติ (ADMIN + ผู้บริหาร)

| รายงาน | เลือก | เนื้อหา |
|---|---|---|
| รายวัน | วันที่ | ทุกคน: เวลาเข้า/ออก, สถานะ, สาย (นาที), ระยะห่าง, หมายเหตุ + ลิงก์ตำแหน่งตอนเข้า/ออก · สรุป: มา/สาย/ลา/ขาด/ไม่ลงเวลาเข้า/ไม่ลงเวลาออก/ยังไม่ลงเวลา · แถบสัดส่วน |

## 7. ปฏิทินวันหยุด (ADMIN แก้ไข / ผู้บริหารดู)

- **เตือนวันหยุดทางพุทธศาสนา**: ระบบมีวันหยุดราชการครบถึงปี พ.ศ. 2570 ตั้งแต่ปี 2571 วันมาฆบูชา วิสาขบูชา อาสาฬหบูชา และเข้าพรรษา (ซึ่งเปลี่ยนวันทุกปี) ต้องเพิ่มเองตามประกาศ — หน้าภาพรวมจะเตือนตั้งแต่เดือนตุลาคมของปีก่อนหน้า จนกว่าจะเพิ่มแล้ว (ปุ่ม **ไปปฏิทินวันหยุด**)

- **ปุ่มลัดวันปิดภาคเรียน**: เลือกปี → กด **ปิดภาคเรียนที่ 2 (เม.ย.–พ.ค.)** หรือ **ปิดภาคเรียนที่ 1 (ต.ค.)** ระบบกรอกช่วงวันที่โดยประมาณ (1 เม.ย.–15 พ.ค. / 11–31 ต.ค.) และชื่อให้ → ปรับวันที่ตามปฏิทินการศึกษาของเขตพื้นที่ → **บันทึก**
- การเพิ่มเป็นช่วงหลายวัน **ไม่ทับวันหยุดราชการเดิม** ในช่วงนั้น (เช่น สงกรานต์ยังเป็นวันหยุดราชการ) — ถ้าต้องการแก้วันใดวันหนึ่ง ให้เลือกวันเดียว

- **วันทำงานประจำสัปดาห์** ตั้งในหน้าตั้งค่า (เริ่มต้น จันทร์–ศุกร์)
- **เพิ่มวันหยุด/วันทำงานพิเศษ**: เลือกช่วงวันที่ + ประเภท + ชื่อ เช่น
  - วันหยุดราชการ: วันมาฆบูชา, วันหยุดชดเชย
  - วันหยุดพิเศษ: ปิดภาคเรียน, หยุดกีฬาสี
  - วันทำงานพิเศษ: ทำงานวันเสาร์ชดเชย (ระบบจะนับเป็นวันทำงาน)
- **วันหยุดราชการไทยเพิ่มให้อัตโนมัติ** ทุกปี (ตอนติดตั้ง/อัปเดต และงานรายคืน สำหรับปีปัจจุบันและปีหน้า):
  - **พ.ศ. 2569** ครบทุกวัน: วันขึ้นปีใหม่, วันหยุดพิเศษ 2 ม.ค., มาฆบูชา, จักรี, สงกรานต์, ฉัตรมงคล, วิสาขบูชา + ชดเชย 1 มิ.ย., 3 มิ.ย., 28 ก.ค., อาสาฬหบูชา, เข้าพรรษา, วันแม่, 13 ต.ค., 23 ต.ค., วันพ่อ + ชดเชย 7 ธ.ค., รัฐธรรมนูญ, สิ้นปี
  - **พ.ศ. 2570** เป็น**ร่าง**ตามปฏิทินที่เผยแพร่ (ยังรอมติ ครม.) — ตรวจสอบเมื่อประกาศ แล้วแก้ไข/ลบ/เพิ่มได้
  - **ปีอื่น ๆ**: เพิ่มวันหยุดที่มีวันที่คงที่ + **คำนวณวันหยุดชดเชยอัตโนมัติ** เมื่อตรงกับเสาร์-อาทิตย์ — วันหยุดทางพุทธศาสนาและวันหยุดพิเศษตามมติ ครม. ให้เพิ่มเอง (ข้อความใต้ปุ่มจะบอกว่าข้อมูลปีนั้นครบหรือไม่)
  - ถ้าลบวันหยุดใดออก (เช่น โรงเรียนเปิดสอน) ระบบจะ**ไม่เพิ่มกลับมาเอง**; ปุ่ม **เพิ่มวันหยุดราชการไทยของปีที่เลือก** ใช้เพิ่มวันที่ขาดกลับเข้ามาได้ทุกเมื่อ
- **เพิ่มวันหยุดของโรงเรียนเอง**: เลือกช่วงวันที่ + ประเภท + ชื่อ → บันทึก (เลือกหลายวันได้ เช่น ปิดภาคเรียน 2 สัปดาห์)
- **แก้ไข**: กดไอคอนดินสอที่รายการ → ระบบเติมข้อมูลลงฟอร์ม → แก้ชื่อ/ประเภท → บันทึก · **ลบ**: กดไอคอนถังขยะ
- ควรตั้งปฏิทินล่วงหน้า เพราะวันหยุดมีผลต่อการนับ “ขาดงาน” และจำนวนวันลา

- **พื้นที่ Google Drive**: แสดงพื้นที่ที่ใช้ของบัญชีระบบ และหน้าภาพรวมจะเตือนเมื่อใช้เกิน 85% (ถ้าเต็ม ระบบจะบันทึกข้อมูลไม่ได้ — ดู [ข้อจำกัด](08-limitations.md))

## 9. ประวัติการใช้งาน — Audit Log (ADMIN)

บันทึกการกระทำสำคัญทั้งหมดแบบเพิ่มต่อท้าย: เข้า/ออกจากระบบ, ล็อกบัญชี, สมัคร/อนุมัติ, แก้ไขข้อมูลบุคลากร, รีเซ็ตรหัสผ่าน, เปลี่ยนสิทธิ์, ลงเวลาไม่ผ่าน GPS (เก็บเฉพาะระยะทาง), การลา, คำร้อง (พร้อมข้อมูลก่อน/หลัง), ตั้งค่า, ปฏิทิน, ส่งออกรายงาน และ **ความพยายามเข้าถึงโดยไม่มีสิทธิ์** (แสดงป้ายสีแดง) — ค้นหาและกรองตามประเภทการกระทำได้

## 10. แชร์ระบบ / QR Code และบัตรเข้าใช้งาน (ADMIN + ผู้บริหาร)

- **QR Code เข้าใช้งาน**: ระบบสร้างจากลิงก์เว็บแอป (`/exec`) ให้อัตโนมัติ — สร้างในเครื่อง ไม่ส่งลิงก์ไปบริการภายนอก
  - **พิมพ์ประกาศ QR (A4)** สำหรับติดห้องพักครู/จุดลงเวลา พร้อมขั้นตอนใช้งาน 5 ข้อ
  - **ดาวน์โหลดรูป QR** (PNG) ไว้ใส่เอกสาร/สไลด์ · **คัดลอกลิงก์**
  - ถ้าลิงก์ที่ระบบใส่ให้ไม่ถูกต้อง (เช่น บัญชี Google Workspace บางแบบ) วางลิงก์ `/exec` จากหน้า Deploy แทนได้
- **ข้อความสำหรับกลุ่ม LINE**: กดคัดลอกแล้ววางในกลุ่ม — ลิงก์มี `openExternalBrowser=1` ทำให้ LINE เปิดด้วย Chrome/Safari (GPS และการจำการเข้าสู่ระบบทำงานได้ดีกว่าเบราว์เซอร์ในแอป LINE)
- **เพิ่มบุคลากรหลายคน** (ADMIN — ปุ่มในหน้านี้ หรือ **จัดการสมาชิก → เพิ่มหลายคน**):
  1. คัดลอกตารางจาก Excel/Google Sheets มาวาง: **ชื่อ-นามสกุล · ตำแหน่ง** — ไม่ต้องใส่รหัสบุคลากร ระบบกำหนดให้ (T001, T002, …) ถ้ามีรหัสเดิมให้ใส่เป็นคอลัมน์แรก (ชื่อ/นามสกุลแยกคอลัมน์ได้, มีแถวหัวตาราง/คอลัมน์ลำดับ 1,2,3 ได้, ไม่ใส่ตำแหน่ง = ครู)
  2. ระบบแสดงตัวอย่างและตรวจทุกแถว (รหัสซ้ำ, ไม่มีนามสกุล ฯลฯ) — **ถ้ามีแถวผิด จะยังไม่สร้างบัญชีใดเลย** แก้แล้วกดใหม่ได้ทันที
  3. กด **สร้างบัญชี** (ครั้งละไม่เกิน 50 คน) → ชื่อผู้ใช้สร้างจากรหัสบุคลากร (เช่น `T001` → `t001`, `1234` → `t1234`) + รหัสผ่านชั่วคราวสุ่ม
  4. กด **พิมพ์บัตรเข้าใช้งาน** (8 ใบต่อ A4 มี QR Code) ตัดแจกแต่ละคน — รหัสผ่านชั่วคราวแสดงครั้งเดียว ทุกคนต้องตั้งรหัสใหม่เมื่อเข้าครั้งแรก
  - ตำแหน่งที่พิมพ์มาจะถูกแปลงเป็นตำแหน่งในระบบ เช่น ครูชำนาญการ/ครูผู้ช่วย → ครู, ธุรการ/การเงิน/พัสดุ → บุคลากรทางการศึกษา
- เพิ่มบุคลากรทีละคนหรือรีเซ็ตรหัสผ่าน ก็มีปุ่ม **พิมพ์บัตรเข้าใช้งาน** ในหน้าต่างรหัสผ่านชั่วคราวเช่นกัน

## 11. แนวปฏิบัติที่แนะนำ

- **ทุกวัน**: ดูภาพรวมหลังเวลาเลิกงาน, พิจารณาใบลา/คำร้องที่ค้าง
- **ทุกสัปดาห์**: ตรวจ Audit Log รายการสีแดง (ACCESS_DENIED / ล็อกบัญชี / ลงเวลาไม่ผ่าน GPS ซ้ำ ๆ)
- **ทุกเดือน**: ส่งออกรายงานรายเดือน (Excel/PDF) เสนอผู้อำนวยการ และสำรองไฟล์ฐานข้อมูล (ไฟล์ → ดาวน์โหลด .xlsx)
- **ต้นปี/ต้นภาคเรียน**: ตั้งปฏิทินวันหยุดทั้งปี, ตรวจรายชื่อบุคลากร ปิดใช้งานผู้ย้ายออก
- ห้ามแชร์ไฟล์ Google Sheets ฐานข้อมูลแบบสาธารณะ ห้ามลบ `PASSWORD_PEPPER` ใน Script Properties
- หลีกเลี่ยงการแก้ไขข้อมูลในชีตโดยตรง (จะไม่มี Audit Log) — ถ้าจำเป็นให้รัน “คำนวณสรุปรายวันใหม่” ของเดือนนั้นหลังแก้
