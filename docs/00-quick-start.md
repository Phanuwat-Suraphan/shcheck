# ติดตั้งแบบง่าย (แนะนำ) — วาง 3 ไฟล์ แล้วเปิดเว็บ

> ใช้เวลาประมาณ 10 นาที · ไม่ต้องรันโค้ด · ไม่ต้องตั้ง Script Properties · ทำบนคอมพิวเตอร์ด้วย Chrome
> ไฟล์ที่ใช้อยู่ในโฟลเดอร์ [`dist/`](../dist/) มี 3 ไฟล์: `Code.gs`, `Index.html`, `Admin.html`

## ขั้นที่ 1 — สร้างโปรเจกต์ Apps Script

1. ล็อกอิน **บัญชี Google ของโรงเรียน** (แนะนำบัญชีกลาง ไม่ใช่บัญชีส่วนตัวของครู)
2. เปิด <https://script.new> → จะได้โปรเจกต์ใหม่ที่มีไฟล์ `Code.gs`
3. (ไม่บังคับ) คลิกชื่อ “โปรเจกต์ที่ไม่มีชื่อ” มุมซ้ายบน ตั้งชื่อเป็น `ระบบลงเวลา วัดเสาหิน`

## ขั้นที่ 2 — วางโค้ด 3 ไฟล์

> วิธีคัดลอกจาก GitHub: เปิดไฟล์ใน `dist/` แล้วกดปุ่ม **Copy raw file** (ไอคอนสี่เหลี่ยมซ้อนกัน มุมขวาบนของกรอบโค้ด)

| ลำดับ | ทำอะไร | วางโค้ดจาก |
|---|---|---|
| 1 | คลิกไฟล์ **Code.gs** → ลบโค้ดเดิมทั้งหมด → วาง | [`dist/Code.gs`](../dist/Code.gs) |
| 2 | กด **+** ข้างคำว่า “ไฟล์” → **HTML** → พิมพ์ชื่อ `Index` (ไม่ต้องพิมพ์ .html) → ลบโค้ดเดิม → วาง | [`dist/Index.html`](../dist/Index.html) |
| 3 | กด **+** → **HTML** → พิมพ์ชื่อ `Admin` → ลบโค้ดเดิม → วาง | [`dist/Admin.html`](../dist/Admin.html) |

กด 💾 **บันทึกโปรเจกต์** (หรือ Ctrl+S) — ชื่อไฟล์ต้องเป็น `Code`, `Index`, `Admin` ตรงตัวพิมพ์ใหญ่-เล็ก

## ขั้นที่ 3 — Deploy เป็นเว็บแอป

1. มุมขวาบน **การทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่ (New deployment)**
2. กด ⚙ ข้าง “เลือกประเภท” → **เว็บแอป (Web app)**
3. ตั้งค่า:
   - **ดำเนินการในฐานะ: ฉัน (Me)**
   - **ผู้มีสิทธิ์เข้าถึง: ทุกคน (Anyone)**
4. กด **Deploy** → ถ้ามีปุ่ม **อนุญาตการเข้าถึง (Authorize access)** ให้กด → เลือกบัญชีโรงเรียน →
   ถ้าขึ้น “Google ยังไม่ได้ยืนยันแอปนี้” ให้กด **ขั้นสูง (Advanced) → ไปที่ … (ไม่ปลอดภัย)** → **อนุญาต (Allow)**
   *(ข้อความนี้ปกติสำหรับโปรแกรมที่โรงเรียนติดตั้งใช้เอง)*
5. คัดลอก **URL ของเว็บแอป** (ลงท้ายด้วย `/exec`)

## ขั้นที่ 4 — เปิดเว็บครั้งแรก แล้วสร้างผู้ดูแลระบบ

1. เปิด URL จากขั้นที่ 3 — ครั้งแรกระบบจะ **สร้างฐานข้อมูลให้อัตโนมัติ** (รอ 10–30 วินาที) แล้วแสดงหน้า **“เริ่มต้นใช้งานระบบ”**
2. เปิดแท็บใหม่ไปที่ <https://drive.google.com> → เปิดไฟล์ **ฐานข้อมูลระบบลงเวลา โรงเรียนวัดเสาหิน** → ชีต **เริ่มต้นใช้งาน** → คัดลอก **รหัสติดตั้ง** (ตัวใหญ่สีแดง เช่น `K7QM-2XPA-9DTE`)
   *(มีเพียงเจ้าของบัญชีที่เห็นรหัสนี้ คนอื่นที่ได้ลิงก์ไปก่อนจึงยึดสิทธิ์ผู้ดูแลระบบไม่ได้)*
3. กลับมาที่หน้าเว็บ กรอก:
   - รหัสติดตั้ง
   - ชื่อ-นามสกุล, รหัสบุคลากร, ตำแหน่ง, ชื่อผู้ใช้, รหัสผ่าน (อย่างน้อย 8 ตัว มีตัวอักษรอังกฤษ+ตัวเลข) ของผู้ดูแลระบบ
   - **พิกัดโรงเรียน** — ถ้ากำลังอยู่ที่โรงเรียน ยืนกลางโรงเรียนในที่โล่งแล้วกด **ใช้ตำแหน่งปัจจุบันของฉัน** (ถ้าไม่อยู่ ข้ามได้ แล้วไปตั้งภายหลังที่เมนูตั้งค่าระบบ)
   - **เวลาเริ่มงาน / เวลาที่ถือว่าสาย / เวลาเลิกงาน** ตามระเบียบของโรงเรียน
4. กด **เริ่มใช้งานระบบ** → เข้าสู่ระบบทันที ชีต “เริ่มต้นใช้งาน” และรหัสจะถูกลบอัตโนมัติ

## ขั้นที่ 5 — ตั้งค่าที่เหลือเล็กน้อย แล้วแจกให้ครู

1. กดปุ่ม **ผู้บริหาร/Admin** → **ปฏิทินวันหยุด** → **เพิ่มวันหยุดราชการที่มีวันที่คงที่ของปีนี้** (แล้วเพิ่มวันหยุดทางพุทธศาสนา/ชดเชย/ปิดภาคเรียนตามประกาศ)
2. ถ้ายังไม่ได้ตั้งพิกัด: **ตั้งค่าระบบ** → ใช้ตำแหน่งปัจจุบัน (ทำที่โรงเรียน) หรือคัดลอกพิกัดจาก Google Maps → บันทึก
3. ลองกด **ลงเวลาเข้างาน** ด้วยโทรศัพท์ของตนเองในโรงเรียน 1 ครั้ง
4. ส่ง URL ให้ครู (แนะนำทำ QR Code) และบอกให้เปิดด้วย Chrome/Safari ไม่ใช่ในแอป LINE → ครูกด **สมัครสมาชิก** → คุณอนุมัติในเมนู **อนุมัติสมาชิก**

เสร็จแล้ว 🎉 — คู่มือการใช้งาน: [ครูและบุคลากร](04-user-guide.md) · [ผู้ดูแลระบบ](05-admin-guide.md)

### คำถามที่พบบ่อย

- **ไม่เห็นไฟล์ฐานข้อมูลใน Drive** → ตรวจว่าเปิดเว็บแอปแล้วอย่างน้อย 1 ครั้ง และดู Drive ของบัญชีเดียวกับที่ Deploy (เมนู “ล่าสุด”)
- **หน้าเว็บแจ้ง “ติดตั้งอัตโนมัติไม่สำเร็จ”** → เปิดโปรเจกต์ Apps Script เลือกฟังก์ชัน `SetupSystem` แล้วกด ▶ เรียกใช้ 1 ครั้ง (อนุญาตสิทธิ์) แล้วเปิดเว็บใหม่
- **กรอกรหัสผิดหลายครั้ง** → ระบบล็อกการกรอกรหัส 1 ชั่วโมง (ป้องกันการเดารหัส)
- **แก้โค้ด/อัปเดตเวอร์ชันใหม่** → วางไฟล์ใหม่ทับ → **Deploy → จัดการการทำให้ใช้งานได้ → ✏️ แก้ไข → เวอร์ชัน: เวอร์ชันใหม่ → Deploy** (URL เดิมใช้ต่อได้ ฐานข้อมูลปรับตัวเองอัตโนมัติ) — ดู [การพัฒนาและอัปเดตระบบ](09-development.md)
- **เปิด URL แล้วขึ้น “Sorry, unable to open the file at this time”** → มักเกิดจากเบราว์เซอร์ล็อกอิน Google หลายบัญชีพร้อมกัน ให้เปิด URL ในหน้าต่างไม่ระบุตัวตน (Ctrl+Shift+N) หรือออกจากบัญชีอื่น และตรวจว่า URL เป็นรูปแบบ `https://script.google.com/macros/s/…/exec` (ไม่มี `/u/1/`)
- **ห้ามลบ** Script Property `PASSWORD_PEPPER` และห้ามแชร์ไฟล์ฐานข้อมูลให้คนอื่น
- ต้องการติดตั้งแบบแยกไฟล์ (17 ไฟล์) หรือใช้ clasp → [คู่มือติดตั้งฉบับเต็ม](03-installation.md)
