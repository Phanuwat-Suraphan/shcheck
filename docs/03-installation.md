# คู่มือติดตั้ง ตั้งค่า และ Deploy

> ใช้เวลาประมาณ 20–30 นาที ไม่ต้องติดตั้งโปรแกรมใด ๆ ทำได้จากเว็บเบราว์เซอร์บนคอมพิวเตอร์

## 0. สิ่งที่ต้องเตรียม

| รายการ | คำแนะนำ |
|---|---|
| บัญชี Google | แนะนำ **บัญชีกลางของโรงเรียน** (เช่น บัญชี Gmail ที่สร้างไว้สำหรับงานธุรการ หรือบัญชี Google Workspace for Education ของโรงเรียน) ไม่ควรใช้บัญชีส่วนตัวของครูคนใดคนหนึ่ง เพราะระบบทำงานในนามบัญชีนี้ และข้อมูลทั้งหมดอยู่ใน Google Drive ของบัญชีนี้ |
| คอมพิวเตอร์ | ใช้ Google Chrome |
| ไฟล์โค้ด | โฟลเดอร์ `src/` ใน Repository นี้ (8 ไฟล์ .gs + 8 ไฟล์ .html + appsscript.json) |
| พิกัดโรงเรียน | หาได้ภายหลังจากหน้าตั้งค่าระบบ (ดูข้อ 6) |

## 1. สร้างฐานข้อมูล Google Sheets และโปรเจกต์ Apps Script

1. เปิด <https://sheets.new> (สร้าง Google Sheet ใหม่) ตั้งชื่อ เช่น `ฐานข้อมูลระบบลงเวลา โรงเรียนวัดเสาหิน`
2. เมนู **ส่วนขยาย (Extensions) → Apps Script** จะเปิดหน้าแก้ไขโค้ดในแท็บใหม่
3. ตั้งชื่อโปรเจกต์ (มุมซ้ายบน) เช่น `WatSaoHin Attendance`

> Spreadsheet นี้คือฐานข้อมูล ห้ามแชร์แบบ “ทุกคนที่มีลิงก์” ระบบไม่ต้องแชร์ไฟล์ให้ครูเลย ครูเข้าใช้ผ่าน URL ของเว็บแอปเท่านั้น

## 2. คัดลอกโค้ดเข้าโปรเจกต์

1. ไปที่ **การตั้งค่าโปรเจกต์ (⚙ Project Settings)** → ติ๊ก **แสดงไฟล์ Manifest "appsscript.json" ในเครื่องมือแก้ไข**
2. กลับไปหน้า **เครื่องมือแก้ไข (Editor `< >`)** แล้วสร้างไฟล์ให้ครบตามตาราง (กด **+** ข้างคำว่า “ไฟล์” → เลือก **สคริปต์** หรือ **HTML** แล้วพิมพ์ชื่อ **โดยไม่ต้องใส่นามสกุล**)
3. เปิดไฟล์ใน `src/` ทีละไฟล์ คัดลอก **ทั้งหมด** ไปวางทับเนื้อหาในไฟล์ชื่อเดียวกัน แล้วกด 💾 บันทึก

| ประเภท | ชื่อไฟล์ใน Apps Script | คัดลอกจาก |
|---|---|---|
| Manifest | `appsscript.json` (มีอยู่แล้ว — วางทับ) | `src/appsscript.json` |
| สคริปต์ | `Code` (มีอยู่แล้วชื่อ Code.gs — วางทับ) | `src/Code.gs` |
| สคริปต์ | `Auth`, `Crypto`, `Attendance`, `Leave`, `Admin`, `Reports`, `Database` | `src/*.gs` |
| HTML | `Index`, `Login`, `Register`, `Dashboard`, `AdminDashboard`, `AdminScript`, `Styles`, `JavaScript` | `src/*.html` |

ตรวจสอบว่ามีไฟล์ครบ **8 ไฟล์ .gs + 8 ไฟล์ .html + appsscript.json** และชื่อไฟล์ตรงตามตารางทุกตัวอักษร (ตัวพิมพ์ใหญ่-เล็กมีผล)

> **ทางเลือกสำหรับนักพัฒนา (clasp):** `npm i -g @google/clasp` → `clasp login` → คัดลอก `.clasp.json.example` เป็น `.clasp.json` แล้วใส่ `scriptId` ของโปรเจกต์ → `clasp push` (ไฟล์ทั้งหมดใน `src/` จะถูกอัปโหลด)

## 3. รัน `SetupSystem()` — สร้างชีตและค่าเริ่มต้นอัตโนมัติ

1. ในแถบเครื่องมือด้านบน เลือกฟังก์ชัน **`SetupSystem`** แล้วกด **▶ เรียกใช้ (Run)**
2. ครั้งแรกจะมีหน้าขอสิทธิ์: **ตรวจสอบสิทธิ์ (Review permissions)** → เลือกบัญชีโรงเรียน → หากขึ้น “Google ยังไม่ได้ยืนยันแอปนี้” ให้กด **ขั้นสูง (Advanced) → ไปที่ WatSaoHin Attendance (ไม่ปลอดภัย)** → **อนุญาต (Allow)**
   - ข้อความนี้ปกติสำหรับสคริปต์ที่โรงเรียนเขียนใช้เอง สิทธิ์ที่ขอ: Google Sheets, Google Drive (เอกสารแนบ/ส่งออกรายงาน), เชื่อมต่อภายนอก (ใช้ส่งออก Excel/PDF จาก Google Sheets เท่านั้น), Trigger, อีเมลของเจ้าของ (ใช้ยืนยันว่าเป็นเจ้าของโปรเจกต์)
3. ดูผลใน **บันทึกการดำเนินการ (Execution log)** ควรเห็น `✔ สร้างชีต ...` ครบ 9 ชีต และ `ติดตั้งระบบเสร็จสมบูรณ์ ✔`

`SetupSystem()` จะ:
- สร้างชีต `Employees, AttendanceLogs, DailySummary, WorkCalendar, Settings, LeaveRequests, CorrectionRequests, AuditLogs, Sessions` พร้อมหัวตาราง (ดู [โครงสร้างฐานข้อมูล](02-database.md))
- ใส่การตั้งค่าเริ่มต้น (รัศมี 150 ม., GPS ≤ 50 ม., เวลาทำงานตัวอย่าง 08:00–16:30 สายหลัง 08:30)
- สร้างกุญแจเข้ารหัส `PASSWORD_PEPPER` ใน Script Properties (**ห้ามลบ/แก้ไขเด็ดขาด**)
- สร้างโฟลเดอร์ Google Drive `WatSaoHin-Attendance-Data (ห้ามแชร์สาธารณะ)` สำหรับเอกสารแนบ
- ติดตั้ง Trigger `DailyMaintenance` เวลา 02:00 น. ทุกวัน (ลบพิกัด GPS ที่เกินระยะเวลาเก็บรักษา)

**เรียกซ้ำได้อย่างปลอดภัย** — ไม่สร้างชีตซ้ำ ไม่ลบข้อมูล ไม่เปลี่ยนกุญแจ (ใช้ตอนอัปเดตเวอร์ชันเพื่อเพิ่มคอลัมน์ใหม่ได้)

## 4. สร้างผู้ดูแลระบบคนแรก (Bootstrap อย่างปลอดภัย)

ระบบ **ไม่มี** Username/Password ของ Admin ฝังในโค้ด ผู้ติดตั้งกำหนดเองผ่าน Script Properties ซึ่งมองเห็นได้เฉพาะเจ้าของโปรเจกต์

1. **⚙ การตั้งค่าโปรเจกต์ → พร็อพเพอร์ตี้ของสคริปต์ (Script Properties) → เพิ่มพร็อพเพอร์ตี้ของสคริปต์**

   | Property | ตัวอย่างค่า | หมายเหตุ |
   |---|---|---|
   | `BOOTSTRAP_ADMIN_USERNAME` | `admin.saohin` | a-z 0-9 . _ - ยาว 4–30 ตัว |
   | `BOOTSTRAP_ADMIN_PASSWORD` | (ตั้งเองอย่างน้อย 8 ตัว มีตัวอักษรอังกฤษ+ตัวเลข) | **ระบบลบทิ้งอัตโนมัติหลังสร้างบัญชี** |
   | `BOOTSTRAP_ADMIN_FULLNAME` | `นายสมชาย ใจดี` | ต้องมีเว้นวรรคระหว่างชื่อ-นามสกุล |
   | `BOOTSTRAP_ADMIN_STAFFCODE` | `1001` | รหัสประจำตัวบุคลากร |
   | `BOOTSTRAP_ADMIN_POSITION` | `ครู` | ไม่บังคับ: ผู้อำนวยการ / ครู / บุคลากรทางการศึกษา / เจ้าหน้าที่อื่น ๆ |

2. กด **บันทึกพร็อพเพอร์ตี้ของสคริปต์**
3. กลับไปหน้า Editor เลือกฟังก์ชัน **`CreateFirstAdmin`** → **▶ Run**
4. Execution log ต้องแสดง `✔ สร้างผู้ดูแลระบบ ... เรียบร้อย` และ `✔ ลบ BOOTSTRAP_ADMIN_PASSWORD ...` — ตรวจใน Script Properties ว่า `BOOTSTRAP_ADMIN_PASSWORD` หายไปแล้ว
5. เมื่อเข้าสู่ระบบครั้งแรก ระบบจะ **บังคับให้เปลี่ยนรหัสผ่าน** ทันที (รหัสที่เคยอยู่ใน Script Properties จึงใช้ต่อไม่ได้)

> `CreateFirstAdmin` ทำงานได้เฉพาะเมื่อยังไม่มี Admin ที่ใช้งานอยู่ และเรียกจากเว็บไม่ได้ (ตรวจว่าเป็นเจ้าของโปรเจกต์ที่รันจาก Editor)
>
> **กู้คืน Admin (ลืมรหัสผ่าน/ถูกปิดใช้งาน):** ตั้ง `BOOTSTRAP_ADMIN_USERNAME` (บัญชีที่จะกู้) + `BOOTSTRAP_ADMIN_PASSWORD` (รหัสใหม่) แล้วรัน **`EmergencyResetAdmin`** จาก Editor

### (แนะนำ) ปรับความเร็วการเข้ารหัสรหัสผ่าน

รันฟังก์ชัน **`BenchmarkPasswordHashing`** — ระบบจะวัดเวลาบนเซิร์ฟเวอร์ Google จริงและแนะนำค่า `PBKDF2_ITERATIONS` สำหรับเวลาประมาณ 1 วินาที หากการเข้าสู่ระบบช้ากว่า 3 วินาที ให้ปรับค่าใน Script Properties (ไม่ต่ำกว่า 20,000) รหัสผ่านเดิมจะถูกปรับอัตโนมัติเมื่อผู้ใช้เข้าสู่ระบบครั้งถัดไป

## 5. Deploy เป็น Web Application

1. มุมขวาบน **การทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่ (New deployment)**
2. กด ⚙ ข้าง “เลือกประเภท” → **เว็บแอป (Web app)**
3. ตั้งค่า:
   - คำอธิบาย: `v1.0.0`
   - **ดำเนินการในฐานะ (Execute as): ฉัน (Me)** ← ระบบอ่าน/เขียน Sheets ในนามบัญชีโรงเรียน ครูไม่ต้องมีสิทธิ์ในไฟล์
   - **ผู้มีสิทธิ์เข้าถึง (Who has access): ทุกคน (Anyone)** ← ครูไม่ต้องล็อกอิน Google ใช้ Username/Password ของระบบแทน
4. กด **Deploy** → คัดลอก **URL ของเว็บแอป** (ลงท้ายด้วย `/exec`) — นี่คือ URL ที่แจกให้ครู (ใช้ HTTPS อัตโนมัติ)
5. ทดสอบเปิด URL ในหน้าต่างไม่ระบุตัวตน (Incognito) ต้องเห็นหน้าเข้าสู่ระบบ

> โรงเรียนที่ใช้ Google Workspace ซึ่งผู้ดูแลโดเมนปิดตัวเลือก “Anyone” ให้เลือก “ทุกคนในโดเมน …” แทน (ครูต้องล็อกอินบัญชีโดเมนก่อน แล้วจึงเข้าสู่ระบบด้วย Username ของระบบ)

**การอัปเดตโค้ดภายหลัง:** แก้ไขไฟล์ → บันทึก → **Deploy → จัดการการทำให้ใช้งานได้ (Manage deployments) → ✏️ แก้ไข → เวอร์ชัน: เวอร์ชันใหม่ → Deploy** (URL เดิมยังใช้ได้) และรัน `SetupSystem()` อีกครั้งหากเวอร์ชันใหม่มีคอลัมน์เพิ่ม

## 6. ตั้งค่าครั้งแรกหลัง Deploy (ผู้ดูแลระบบ)

1. เปิด URL เว็บแอป → เข้าสู่ระบบด้วยบัญชี Admin → ตั้งรหัสผ่านใหม่
2. กดปุ่ม **ผู้บริหาร/Admin** (มุมขวาบน) → เมนู **ตั้งค่าระบบ**
3. **ตั้งพิกัดโรงเรียน** (เลือกวิธีใดวิธีหนึ่ง):
   - **วิธีที่ 1 (แนะนำ):** ถือโทรศัพท์ยืนบริเวณกึ่งกลางโรงเรียน (เช่น หน้าเสาธง) ในที่โล่ง เปิดหน้าตั้งค่าบนโทรศัพท์ กด **ใช้ตำแหน่งปัจจุบันของฉัน** รอให้ความแม่นยำต่ำกว่า ±15 ม.
   - **วิธีที่ 2:** เปิด Google Maps บนคอมพิวเตอร์ → คลิกขวาที่กึ่งกลางโรงเรียน → คลิกตัวเลขพิกัดบรรทัดแรก (คัดลอกอัตโนมัติ เช่น `18.xxxxxx, 98.xxxxxx`) → วางตัวแรกในช่องละติจูด ตัวหลังในช่องลองจิจูด
   - กด **ดูบนแผนที่** เพื่อตรวจสอบว่าหมุดอยู่ในโรงเรียน
4. **รัศมีที่อนุญาต** ค่าทดลอง 150 ม. — ควรครอบคลุมอาคารที่ไกลที่สุด + เผื่อความคลาดเคลื่อน GPS ประมาณ 30–50 ม.; ทดลองกด “ตรวจสอบตำแหน่งของฉัน” ที่มุมไกลสุดของโรงเรียนด้วยโทรศัพท์หลายรุ่นแล้วปรับ
5. **ค่าความแม่นยำ GPS สูงสุด** ค่าทดลอง 50 ม. (ต่ำ = เข้มงวด แต่ในอาคารอาจลงเวลายาก)
6. **เวลาปฏิบัติงาน**: เวลาเริ่มงาน, เวลาที่ถือว่ามาสาย, เวลาเลิกงาน, เวลาเปิดให้ลงเวลา, วันทำงานประจำสัปดาห์ — **ปรับตามระเบียบ/คำสั่งของโรงเรียนจริง** (ค่าเริ่มต้นเป็นเพียงตัวอย่าง)
7. เปิดสวิตช์ **ยืนยันว่าได้ตรวจสอบการตั้งค่า...** แล้วกด **บันทึกการตั้งค่า** (แถบเตือนในหน้าภาพรวมจะหายไป)
8. เมนู **ปฏิทินวันหยุด** → กด **เพิ่มวันหยุดราชการที่มีวันที่คงที่ของปีนี้** แล้วเพิ่มวันหยุดทางพุทธศาสนา วันหยุดชดเชย และวันปิดภาคเรียนตามประกาศจริง

## 7. แจกให้ครูใช้งาน

1. ส่ง URL เว็บแอปให้ครู (แนะนำทำ **QR Code** ติดที่ห้องธุรการ หรือย่อ URL ด้วยบริการฟรี)
2. แนะนำให้ครู **เปิดด้วย Chrome (Android) หรือ Safari (iPhone)** ไม่ใช่ในแอป LINE/Facebook (บางครั้งบล็อก GPS) และ **เพิ่มไปยังหน้าจอหลัก** เพื่อเปิดเหมือนแอป
3. ครูสมัครสมาชิก → Admin อนุมัติในเมนู **อนุมัติสมาชิก** (หรือ Admin เพิ่มบุคลากรเองในเมนู **จัดการสมาชิก** แล้วแจ้งรหัสผ่านชั่วคราว)
4. ทดลองใช้คู่ขนานกับวิธีเดิม 1–2 สัปดาห์ก่อนใช้จริง

## 8. การแก้ปัญหาที่พบบ่อย

| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| หน้าเว็บแจ้ง “ระบบยังไม่ได้ติดตั้งฐานข้อมูล” | ยังไม่ได้รัน `SetupSystem()` หรือรันด้วยบัญชีอื่น — รันใหม่จาก Editor ด้วยบัญชีเจ้าของ |
| รัน `SetupSystem` แล้วขึ้น “ต้องรันจาก Apps Script Editor โดยเจ้าของ” | บัญชีที่เปิด Editor ไม่ใช่เจ้าของโปรเจกต์ หรือยังไม่อนุญาตสิทธิ์อีเมล — ตรวจ appsscript.json ว่ามี scope `userinfo.email` แล้วรันใหม่ |
| เข้าสู่ระบบช้า (> 3 วินาที) | รัน `BenchmarkPasswordHashing` แล้วลดค่า `PBKDF2_ITERATIONS` ตามคำแนะนำ |
| ครูกดลงเวลาแล้ว “ไม่ได้รับอนุญาตให้เข้าถึงตำแหน่ง” | เปิดตำแหน่งในโทรศัพท์ และอนุญาตตำแหน่งให้เบราว์เซอร์ (ดูคู่มือครู) / เปิดลิงก์นอกแอป LINE |
| ลงเวลา “สัญญาณ GPS ไม่แม่นยำพอ” บ่อย | ให้ครูออกไปที่โล่งและเปิด Wi-Fi หรือเพิ่ม `ค่าความแม่นยำ GPS สูงสุด` เล็กน้อย (เช่น 70–100 ม.) |
| ครูอยู่ในโรงเรียนแต่ระบบว่าอยู่นอกพื้นที่ | ตรวจพิกัดศูนย์กลาง/รัศมีในหน้าตั้งค่า (กด “ดูบนแผนที่”) |
| Export Excel/PDF ไม่สำเร็จ | ตรวจว่า Deploy ด้วย “Execute as: Me” และอนุญาตสิทธิ์ Drive/เชื่อมต่อภายนอกแล้ว (รันฟังก์ชันใดก็ได้จาก Editor เพื่อให้หน้าขอสิทธิ์แสดงอีกครั้ง) |
| แก้โค้ดแล้วหน้าเว็บไม่เปลี่ยน | ต้อง Deploy เวอร์ชันใหม่ (Manage deployments → แก้ไข → เวอร์ชันใหม่) |
| ลืมรหัสผ่าน Admin คนเดียวของระบบ | ใช้ `EmergencyResetAdmin()` (ข้อ 4) |

## 9. การสำรองข้อมูล (แนะนำ)

- ทุกสิ้นเดือน: เปิด Spreadsheet ฐานข้อมูล → **ไฟล์ → ดาวน์โหลด → Microsoft Excel (.xlsx)** เก็บในที่ปลอดภัย หรือ **ไฟล์ → ทำสำเนา**
- Google Sheets เก็บประวัติเวอร์ชันอัตโนมัติ (**ไฟล์ → ประวัติเวอร์ชัน**) ใช้กู้คืนกรณีมีผู้แก้ไขชีตโดยไม่ตั้งใจ
- อย่าเปลี่ยนชื่อชีต/หัวตาราง และอย่าลบ Script Property `PASSWORD_PEPPER`
